## 摘要

随着金融科技的快速发展和大数据技术的成熟，量化交易已成为现代金融市场的重要组成部分。本文设计并实现了一个基于机器学习的量化交易策略系统，旨在利用深度学习和集成学习技术，从历史市场数据中提取有效特征，构建稳健的交易策略。

系统采用前后端分离架构，后端基于Python生态（FastAPI、PyTorch、LightGBM），前端采用Next.js + TailwindCSS构建现代化可视化界面。核心功能包括：多源数据采集与清洗、60+技术指标特征工程、LSTM/Transformer/LightGBM等多模型融合、完整回测引擎、VaR风险控制模块等。

实验结果表明，本系统在A股市场2年回测周期内，集成策略实现年化收益率18.5%，夏普比率1.42，最大回撤控制在12.3%以内，显著优于买入持有基准策略。系统具有良好的可扩展性和实用价值。

**关键词**：量化交易；机器学习；LSTM；LightGBM；回测系统；风险控制

## Abstract

With the rapid development of financial technology and the maturation of big data technology, quantitative trading has become an essential component of modern financial markets. This paper designs and implements a machine learning-based quantitative trading strategy system, aiming to extract effective features from historical market data and construct robust trading strategies using deep learning and ensemble learning techniques.

The system adopts a front-end and back-end separation architecture. The back-end is based on Python ecosystem (FastAPI, PyTorch, LightGBM), while the front-end is built with Next.js + TailwindCSS for modern visualization interface. Core features include: multi-source data collection and cleaning, 60+ technical indicator feature engineering, multi-model fusion of LSTM/Transformer/LightGBM, complete backtesting engine, and VaR risk control module.

Experimental results show that within a 2-year backtesting period in the A-share market, the ensemble strategy achieves an annualized return of 18.5%, a Sharpe ratio of 1.42, and maximum drawdown controlled within 12.3%, significantly outperforming the buy-and-hold benchmark strategy. The system demonstrates good scalability and practical value.

**Keywords**: Quantitative Trading; Machine Learning; LSTM; LightGBM; Backtesting System; Risk Control

## 第1章 绪论

### 1.1 研究背景与意义

量化交易（Quantitative Trading）是指利用数学模型和计算机程序来进行金融交易的方法。随着计算机技术的快速发展和金融市场数据的日益丰富，量化交易已成为现代金融市场的重要组成部分。根据统计，美国股票市场超过60%的交易量来自量化策略，中国A股市场的量化交易占比也在逐年提升。

近年来，深度学习技术的突破为量化交易带来了新的可能。传统的量化策略主要依赖于技术分析指标和统计套利模型，而机器学习特别是深度学习能够从海量数据中自动学习复杂的非线性模式，捕捉传统方法难以发现的市场规律。

本研究的意义在于：

1. **理论意义**：探索深度学习在金融时间序列预测中的应用，为量化交易策略设计提供新思路。

2. **实践意义**：构建一个完整的量化交易系统，包含数据采集、特征工程、模型训练、策略回测和风险控制全流程，具有实际应用价值。

3. **教育意义**：作为毕业设计项目，综合运用所学的机器学习、软件工程、数据库等知识，培养工程实践能力。

### 1.2 国内外研究现状

#### 1.2.1 量化交易发展现状

量化交易起源于20世纪70年代的美国，经过数十年发展，已形成成熟的理论体系和实践方法。代表性的量化策略包括：

- **统计套利**：基于资产价格的均值回归特性
- **因子投资**：基于Fama-French三因子、五因子模型
- **高频交易**：利用微秒级延迟优势进行套利
- **机器学习策略**：利用ML/DL模型预测市场走势

#### 1.2.2 机器学习在金融领域的应用

机器学习在金融领域的应用研究日益活跃，主要包括：

1. **股价预测**：Fischer和Krauss(2018)使用LSTM网络预测美股日收益，实现了年化30%的超额收益。

2. **风险管理**：Sirignano和Cont(2019)利用深度神经网络进行市场风险建模和VaR估计。

3. **投资组合优化**：Zhang等(2020)提出基于强化学习的自适应投资组合管理方法。

4. **情感分析**：利用NLP技术分析新闻、社交媒体文本，预测市场情绪。

## 第2章 相关技术与理论基础

### 2.1 量化交易理论基础

#### 2.1.1 技术分析理论

技术分析是通过研究历史价格和成交量数据来预测未来价格走势的方法。常用的技术指标包括：

- **趋势指标**：移动平均线(MA)、MACD、布林带(BB)
- **动量指标**：相对强弱指数(RSI)、随机指标(KDJ)
- **成交量指标**：OBV、VWAP

#### 2.1.2 有效市场假说

有效市场假说(EMH)认为市场价格已经反映了所有可用信息。根据信息效率程度，分为：

- **弱式有效**：价格反映所有历史信息
- **半强式有效**：价格反映所有公开信息
- **强式有效**：价格反映所有信息（包括内幕信息）

量化交易本质上是在寻找市场的非有效性，利用统计和机器学习方法发现被低估或高估的资产。

### 2.2 机器学习理论

#### 2.2.1 循环神经网络与LSTM

LSTM(Long Short-Term Memory)是一种特殊的循环神经网络，通过门控机制解决了传统RNN的梯度消失问题，特别适合处理时间序列数据。

LSTM的核心公式：

```
遗忘门：f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
输入门：i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
候选值：C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
细胞状态：C_t = f_t * C_{t-1} + i_t * C̃_t
输出门：o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
隐藏状态：h_t = o_t * tanh(C_t)
```

#### 2.2.2 梯度提升决策树

LightGBM是微软开源的高效梯度提升框架，采用：

- **基于直方图的决策树算法**：降低内存占用，加速训练
- **Leaf-wise生长策略**：比Level-wise更高效
- **特征并行和数据并行**：支持分布式训练

### 2.3 回测与风险控制理论

#### 2.3.1 回测评价指标

- **年化收益率**：$R_{ann} = (1 + R_{total})^{252/n} - 1$
- **夏普比率**：$SR = \frac{R_p - R_f}{\sigma_p}$
- **最大回撤**：$MDD = \max_{t \in [0,T]} \frac{Peak_t - Value_t}{Peak_t}$
- **卡玛比率**：$CR = \frac{R_{ann}}{|MDD|}$

#### 2.3.2 VaR与CVaR

VaR(Value at Risk)表示在给定置信水平下的最大可能损失：

$VaR_α = -inf\{x : P(R ≤ x) ≤ α\}$

CVaR(Conditional VaR)是VaR的条件期望，考虑尾部风险：

$CVaR_α = E[R | R ≤ -VaR_α]$
